# EKC — 環境知識競賽 賽前練習題庫

115 年臺南市環境知識競賽（國小組）賽前練習用的靜態網站。
臺南市安平區新南國小 衛生組製作。

**網址：** https://syu-boming.github.io/EKC/

## 這是什麼

把環境部「環保知識挑戰擂台賽」官方題庫（5687 題，含解答與解析）整理成可以在手機、
平板、電腦上直接練習的網頁。學生打開網址就能用，不用註冊、不用安裝。

- **主題練習** — 依 12 個主題與 4 個難度挑題，答完一題馬上看答案與解析
- **模擬考** — 80 題 / 30 分鐘，完全比照正式比賽規則，時間到自動交卷
- **錯題複習** — 答錯的題目自動收進來，再答對一次才移出
- **重點速記** — 各主題核心考點整理，以及主辦單位指定的 6 支影片清單
- **比賽資訊** — 當天流程、作答規定、證件與領獎注意事項

練習紀錄存在使用者自己瀏覽器的 localStorage，不會上傳到任何伺服器。

## 題庫來源

| 項目 | 內容 |
|------|------|
| 來源檔 | 環境部「環保知識挑戰擂台賽」題庫（有解答）.xls |
| 總題數 | 5687 題（原始 5688 題，去除 1 題完全重複） |
| 難度 | 初級 1269、中級 1542、中高級 1636、高級 1240 |
| 115 年新增 | 2844 題（與 114 年題庫 2844 題比對後新增的部分） |

12 個主題分類與每題的「核心考點」標記，是本專案另外整理的，官方題庫本身沒有這兩欄。

## 檔案結構

```
index.html          頁面外殼
style.css           樣式（支援深色模式）
app.js              全部程式邏輯，無框架、無建置步驟
data/questions.json 題目、選項、答案、主題、難度、考點
data/explain.json   每題解析（背景載入，不擋首屏）
data/notes.json     各主題重點速記與指定影片清單
```

純靜態，沒有任何後端。改完直接 push 就會更新 GitHub Pages。

## 資料怎麼產生的

原始 .xls → `eec/export.py` 清洗去重 → 主題分類 → `eec/build.py` 產出 `data/*.json`
與 Google Drive 上「題庫整理」資料夾的分主題 markdown 與 CSV。
這兩支腳本放在 `C:\school-work-script\eec\`（不在本 repo 內，因為含本機路徑）。
